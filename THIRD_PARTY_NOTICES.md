# Third-Party Notices

The Meadow Balance Lab runtime contains no third-party JavaScript framework,
analytics package, advertising SDK, remote grading service, generative-AI
service, or paid API.

The core application source was created for this project.

The favicon is a self-contained inline SVG using the Unicode seedling
character. No external image is fetched at runtime.

## Development and QA tooling

Chromium and Playwright Core were used externally for browser QA.

They are not bundled as runtime dependencies of the educational website.
